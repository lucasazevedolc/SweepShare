# SweepShare

SweepShare is a RESTful API built with Java and Spring Boot designed to manage and automate the distribution of household chores within shared student apartments (WGs).

## Current Features
- Authentication and session management using JWT (Access Token & Refresh Token Rotation).
- Management of Users and WGs.
- Mapping of shared rooms and tasks categorized by difficulty levels.
- Room and Task assignment scales.

## Technologies Used
- Java 25 / Spring Boot 4
- Spring Security & Java JWT (JJWT)
- Spring Data JPA / MySQL
- MapStruct / Lombok
- Swagger UI (OpenAPI 3)
